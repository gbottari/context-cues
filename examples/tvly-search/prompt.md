Reading `tvly search` results:

- **Read the top `score` before the results.** Relevant hits usually score 0.65–0.90. A top score under about 0.1 means the search failed: the pages it lists are on an unrelated topic, so query again and treat nothing in them as an answer.
- **Query with a product name or one plain phrase.** Stacking units, a brand-plus-spec string and a domain name into one query is the pattern that fails.
